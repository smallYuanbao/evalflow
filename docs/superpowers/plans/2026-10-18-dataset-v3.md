## 运行注意(本次踩到)

- 宿主机休眠后，celery worker 会**静默失去 broker 连接**：任务留在 redis 队列，
  但 worker 不消费，run 永远停在 `progress=0`。处理方式：重启 worker，
  redis 里的待执行任务会被新 worker 接走；确认只有一个 worker 在跑。
- 本次 v3 run 的 rejection 从 0.25 升到 0.75，部分原因是回答措辞恰好命中词表
  （其中 Python 那题属于「口头说超出范围、实际仍作答」的假阳性）。
  拒答指标仍是启发式，单次 run 的数值不能当稳定结论。
