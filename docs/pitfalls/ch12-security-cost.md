# Ch12 踩坑:安全与成本(鉴权 + 限流 + 费用统计)

> 这一章给平台加「访问鉴权 + 防刷限流 + 费用统计」三件套。坑主要在「中间件顺序」「线程复用」「计量兜底」「滑动窗口语义」。

## 坑 1:鉴权中间件要注册在 CORS 之内,否则 401 变 CORS 报错

**现象**:前端设了密钥但访问被拒时,控制台报的是 CORS 跨域错误,而不是 401;界面显示「网络异常」而非「未登录」。

**根因**:FastAPI/Starlette 的中间件是「**后注册的在外层**」。如果鉴权中间件注册在 CORS 之后(外层),它返回的 401 响应不经过 CORS 中间件,就没有 `Access-Control-Allow-Origin` 头,浏览器 fetch 直接拦截,前端根本读不到状态码。

**修法**:鉴权中间件**先**注册(内层),CORS **后**注册(外层),让 401 也被最外层「包一层 CORS 头」再回给浏览器。真机验证:401 响应带 `Origin` 时确实带上了 `access-control-allow-origin`。

**原理**:中间件是洋葱模型——越外层越先处理请求、越晚处理响应。带错误码的响应也要穿过最外层中间件,才能正确回传给浏览器。

## 坑 2:线程局部 token 计量要配合 reset_usage

**现象**:如果不在每个样本开头归零,后一个样本会「继承」前一个样本的 token 累计,费用算错。

**根因**:`threading.local` 是「**每线程一份**」,不是「每任务一份」。Ch10 的 `ThreadPoolExecutor` 复用线程,同一个线程会先后执行不同的样本。

**修法**:每个样本开头 `reset_usage()` 归零、结尾 `get_usage()` 取累计。线程复用时靠 reset 重建作用域边界。

**原理**:线程局部解决「并发隔离」,但解决不了「复用串味」;凡是复用资源的场景,都要显式重置状态。

## 坑 3:openai 响应的 usage 可能为 None

**现象**:测试 mock 或某些兼容接口不返回 usage 时,`_add_usage(r.usage)` 直接 `AttributeError` 崩溃,整个评测挂掉。

**根因**:openai 的 `CompletionUsage` 不是每次必返(测试 mock 的 `_fake_resp` 就没有 usage 字段)。

**修法**:双重兜底——`getattr(r, "usage", None)` 判空 + `usage.prompt_tokens or 0` 防 None 值。拿不到 usage 就当 0 计,不崩。

**原理**:费用计量是「锦上添花」,**绝不能因为拿不到 usage 就把评测本身搞崩**。旁路数据一律容错。

## 坑 4:限流是滑动窗口,连发验证要一气呵成

**现象**:真机验证限流时,连发 4 次全 200,一度以为限流失效;再发 6 次却全 429。

**根因**:60s **滑动窗口**,每次 `allow()` 会先把「距今 ≥ 60s」的旧时间戳清掉。真实 run 的发起距那轮连发已经隔了轮询等操作超过 60s,旧记录被清,连发又从 0 计数,所以前 4 次都放行;等窗口真正堆满,后面才全 429。

**修法**:验证时用单条脚本**一次性连发**,别中间隔别的操作;理解「滑动窗口 = 只看最近 60s」而非「从固定起点计数」。

**原理**:滑动窗口统计的是「最近一个窗口长度内」的请求,时间一过旧记录自动作废。间隔操作会把验证场景和真实场景混在一起,得出「限流失效」的假结论。

## 坑 5:限流阈值在 import 时固化,改配置不重启不生效

**现象**:测试里 monkeypatch `settings.rate_limit_runs_per_minute`,限流器阈值没变。

**根因**:`run_limiter = SlidingWindowLimiter(settings.rate_limit_runs_per_minute)` 在模块 **import 时**执行,阈值被复制进实例;之后改 settings 不影响已创建的实例。

**修法**:测试直接改实例属性 `monkeypatch.setattr(run_limiter, "max_requests", 2)` + `_reset()`;生产改 .env 要重启进程。

**原理**:模块级单例在 import 时「读一次」配置。凡是 import 时固化的配置,运行时改 source 不会自动同步,要么重建实例、要么重启进程。

## 小结

这一章收敛成一句:**旁路能力(鉴权/计量/限流)别影响主流程,也别被主流程的资源复用带偏**——鉴权要最外层兜住响应、计量拿不到就容错、限流要理解滑动窗口语义。
